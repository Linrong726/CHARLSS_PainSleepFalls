# CHARLS pain and restless sleep reassessment and subsequent falls

This repository contains the analysis and figure code for the longitudinal study of joint pain and restless sleep status at reassessment and subsequent fall reports in older CHARLS participants.

- [Figure reproduction](docs/REPRODUCE.md#reproduce-the-publication-figures) uses six frozen aggregate CSV inputs and a frozen figure-source map supplied with the manuscript as **Additional file 4**.
- [Analysis reconstruction](docs/REPRODUCE.md#reconstruct-the-analysis) uses authorized CHARLS releases and the two frozen aggregate verification records in Additional file 4. See [input files and versions](docs/INPUTS.md).
- [Aggregate results and figure sources](docs/AGGREGATES.md) explains the exact input scope and output scales.

The companion submission's **Additional file 3** is the formatted aggregate workbook. **Additional file 4** is the ZIP archive `CHARLS_PainSleepFalls_Reproducibility_Inputs_v1_0.zip`, supplied as a supplementary file with the manuscript. Obtain that attachment from the manuscript or its published supplementary materials; it is not included in this code-only GitHub tree. The archive README identifies its compatible code version, lists the nine frozen input files and provides a verification and installation utility.

Obtain participant-level data through the official CHARLS access procedures. The input archive does not include participant-level data. This repository contains code and source definitions. No license was added with this deposit.
