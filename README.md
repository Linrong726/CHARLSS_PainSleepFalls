# CHARLS pain and restless sleep reassessment and subsequent falls

This repository contains the analysis and figure code for the longitudinal study of joint pain and restless sleep status at reassessment and subsequent fall reports in older CHARLS participants.

- [Figure reproduction](docs/REPRODUCE.md#reproduce-the-publication-figures) uses the six frozen aggregate CSV inputs from the separate reproducibility package.
- [Analysis reconstruction](docs/REPRODUCE.md#reconstruct-the-analysis) uses authorized CHARLS releases and two frozen verification records from that package. See [input files and versions](docs/INPUTS.md).
- [Aggregate results and figure sources](docs/AGGREGATES.md) describes the separate input files and output scales.

The companion submission's Additional file 3 is the formatted aggregate workbook. Obtain participant-level data through the official CHARLS access procedures. The repository contains code and source definitions. No license was added with this deposit.
